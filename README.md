# Ocean Cleanup Mobile

This folder contains a separate Expo mobile app for Android and iOS.

## Setup

1. Install Expo CLI globally if you don't already have it:
   ```bash
   npm install -g expo-cli
   ```

2. Install dependencies:
   ```bash
   cd mobile
   npm install
   ```

3. Start the app:
   ```bash
   npm run start
   ```

## Notes

- The mobile app uses the same API contract as the web app.
- Configure the API base URL using `APP_API_BASE_URL` in a `.env` file.
